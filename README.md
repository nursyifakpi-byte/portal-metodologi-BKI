Portal Metodologi Interaktif BKI (Digital Professor)

Portal ini adalah media pembelajaran interaktif berbasis web yang dirancang khusus untuk mahasiswa program studi Bimbingan Konseling Islam (BKI). Proyek ini bertujuan untuk memudahkan pemahaman mengenai Metodologi Penelitian Kuantitatif melalui simulasi visual dan bantuan kecerdasan buatan (AI).

✨ Fitur Utama

Pandu Suara AI (TTS): Penjelasan materi secara otomatis oleh narasi suara dosen digital (menggunakan Gemini API).

Simulasi Lab Virtual: Grafik interaktif untuk membedakan desain Eksperimen (Kausalitas) dan Non-Eksperimen (Korelasi).

Asisten Riset Cerdas: Konsultasi judul dan desain riset secara instan menggunakan integrasi LLM.

Desain Responsif: Dapat diakses dengan nyaman melalui perangkat mobile maupun desktop.

🚀 Cara Menjalankan

Clone repositori ini atau unduh file portal_metodologi_lengkap.html.

Buka file tersebut menggunakan peramban web (Chrome, Edge, atau Firefox).

Pastikan perangkat Anda terhubung ke internet untuk memuat pustaka Tailwind CSS, Chart.js, dan akses ke Gemini API.

🔑 Konfigurasi API

Portal ini membutuhkan kunci API dari Google AI Studio agar fitur suara dan asisten AI berfungsi.

Dapatkan kunci API di Google AI Studio.

Buka file HTML dan cari variabel const apiKey.

Masukkan kunci Anda di sana: const apiKey = "KUNCI_ANDA_DI_SINI";.

📚 Referensi Materi

Minggu 4-5: Desain Penelitian Eksperimen (Kausalitas).

Minggu 6-7: Desain Non-Eksperimen (Korelasional & Ex-Post Facto).
